# Narasi Produksi

Untuk pertanyaan [[produksi]], manfaatkan semantic production result via `answer_production(tahun, bulan, periode, mode, wilayah)`. Hasil menyediakan: KPI semantic object, evidence, narrative, short narrative.

Prioritaskan evidence tersebut daripada membuat angka sendiri. Lihat [[batas-data-engine]] dan [[model-evidence]].
