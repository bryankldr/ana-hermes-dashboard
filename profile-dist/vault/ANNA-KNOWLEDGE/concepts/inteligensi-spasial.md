# Inteligensi Spasial

Peta adalah analytical presentation, bukan dekorasi. ANNA memakai peta untuk: lokasi [[petak]], distribusi status, konsentrasi masalah, wilayah tertentu, penghubung KPI–lokasi, spatial drill-down.

Contoh: "Tampilkan petak bongkor" = `Filter [[petak]] (Status=BONGKOR)` + `show_on_map`. Inventaris komponen + op kendali di [[panel-spatial-map]]. Lihat [[penalaran-spasial]] dan [[presentasi-spasial]].
