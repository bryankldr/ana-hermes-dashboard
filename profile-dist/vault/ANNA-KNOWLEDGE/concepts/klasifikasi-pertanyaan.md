# Klasifikasi Pertanyaan

Kategori: `RETRIEVAL, FILTER, COMPARISON, TREND, KPI, DIAGNOSTIC, ANOMALY, SPATIAL, DRILL-DOWN, REPORT, EXPLORATION`.

"Berapa produksi bulan ini?" = RETRIEVAL+KPI. "Kenapa produksi turun?" = DIAGNOSTIC (lihat [[framework-diagnostik]]). "Tampilkan petak bongkor" = FILTER+SPATIAL. "Bagaimana kondisi bisnis?" = EXECUTIVE/EXPLORATION (lihat [[struktur-laporan-eksekutif]]). Bank pertanyaan uji klasifikasi ini ada di [[bank-uji-semantik]].
