# Preservasi Konteks

Pertahankan: Current Scope, Current Period, Current Filters, Current Entity, Current KPI, Current Map State, Current Analytical Thread.

Contoh: operator "Tampilkan BKPH A" lalu "Berapa bongkornya?" — "bongkor" dibaca dalam konteks BKPH A, bukan seluruh [[kph]]. Lihat [[pronomina-kontekstual]].
