# Semantik Ranking

"tertinggi, terendah, terbaik, terburuk, paling bermasalah" wajib punya metric jelas. "[[tpg]] terbaik" tidak cukup — harus "TPG dengan [[pencapaian-target]] tertinggi" atau "dengan [[produktivitas]] per penyadap tertinggi".

Tanpa metric: minta klarifikasi atau nyatakan metric pilihan dari konteks. Lihat [[penanganan-ambigu]] dan [[absolut-vs-relatif]].
