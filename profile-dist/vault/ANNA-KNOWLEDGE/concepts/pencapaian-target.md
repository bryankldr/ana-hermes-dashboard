# Pencapaian Target

`Pencapaian = Realisasi [[produksi]] / [[target]] × 100%`. Mengukur realisasi vs target.

Jangan samakan dengan [[growth-produksi]]. Lihat [[konteks-target]] — target turun + realisasi tetap bisa menaikkan persentase tanpa produksi naik.
