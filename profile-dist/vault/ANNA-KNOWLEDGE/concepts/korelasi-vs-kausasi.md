# Korelasi vs Kausasi

Dilarang menyatakan sebab-akibat dari data observasional. "Aktivitas naik sehingga [[produksi]] naik" tidak valid bila data hanya menunjukkan keduanya naik bersamaan.

Gunakan: "keduanya bergerak bersamaan, tetapi data belum cukup untuk menyimpulkan sebab-akibat." Lihat [[klasifikasi-fakta]] dan [[model-evidence]].
