# Semantik Chart

Chart hanya bila visualisasi membantu menjelaskan data. Perbandingan [[tpg]] → bar, tren waktu → line, komposisi → composition chart, distribusi spasial → map.

Chart wajib punya: title, metric, dimensi, scope, [[periode]]. Tanpa dekorasi. Lihat [[semantik-dashboard]] dan [[presentasi-chart]].
