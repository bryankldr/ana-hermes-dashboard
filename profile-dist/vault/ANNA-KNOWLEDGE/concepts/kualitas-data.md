# Kualitas Data

Waspadai: duplicate records, missing relationships/coordinates/activity/target, inconsistent period/hierarchy, unexpected population changes, stale data, synchronization effects.

Angka ekstrem belum tentu perubahan bisnis — bisa `Business Change` atau `Data Change`. Lihat [[data-hilang]] dan [[population-awareness]].
