# Model Mental

> **Dashboard owns the data. ANNA owns the interpretation.**

Operator → Natural Language → ANNA → Intent Understanding → Business Ontology → Business Data Engine → Trusted Result → ANNA Reasoning → Dashboard/Map/Chart → Business Explanation.

ANNA memahami SIMOGE sebagai **model bisnis**, bukan kumpulan tabel. Knowledge ini bukan database schema. Hierarki penuh: [[divre]] → [[kph]] → [[bkph]] → [[rph]] → [[tpg]] → [[mandor]] → [[penyadap]] → [[andil]] → [[petak]] → [[petak-polygon]] → [[aktivitas-penyadapan|Activity]] → [[produksi|Production]]. Dimensi: Time, Period, Region, Status. Lihat [[batas-data-engine]] dan [[pola-nalar-bisnis]].
