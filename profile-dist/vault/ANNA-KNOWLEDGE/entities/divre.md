# Divre / Regional

Level organisasi/wilayah paling atas dalam struktur wilayah sistem.

## Master nyata (sandbox 2026-10-03)

| kode_divre | Nama resmi | Alias operator |
|---|---|---|
| 1 | JAWA TENGAH | jateng |
| 2 | JAWA TIMUR | jatim |

Sandbox hanya berisi data DIVRE 2 (JAWA TIMUR). "Jabar" (JAWA BARAT) tidak ada
di database ini — bila operator memintanya, klarifikasi bahwa cakupan data
hanya Jatim + Jateng (lihat [[penanganan-ambigu]]).
